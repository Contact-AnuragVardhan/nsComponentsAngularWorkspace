NSComponent allows you to build cross-platform, cross-browser web and mobile apps faster. It is a set of ready-to-use HTML5 components written in pure Javascript with no dependencies on other libraries. These Components can be easily combined into a single application interface of any complexity. Each Component can be easily customized via CSS and Configurations.
The NSComponent components are compatible with popular JavaScript frameworks such as React, Angular. The Components have React and Angular wrapper so that it can be used in both React and Angular Projects.
